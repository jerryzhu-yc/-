# 附录 A　符号、单位与约定

| 符号 | 含义 | 单位 |
|---|---|---|
| $q$ | 关节位置 | rad 或 m |
| $dot q$ | 关节速度 | rad/s 或 m/s |
| $ddot q$ | 关节加速度 | rad/s² 或 m/s² |
| $	au$ | 关节力矩/力 | N·m 或 N |
| $M(q)$ | 惯性矩阵 | 随关节类型而定 |
| $c(q,dot q)$ | 科里奥利与离心项 | N·m 或 N |
| $g(q)$ | 重力项 | N·m 或 N |
| $J(q)$ | 几何雅可比 | 随坐标而定 |
| $T,V$ | 动能、势能 | J |

## 坐标约定

本仓库的平面角度从水平向右的 x 轴逆时针计算。2R 模型中 q1 是第一杆绝对角，q2 是第二杆相对第一杆的角度。使用 SI 单位，代码中的角度均为弧度。

## 代码接口

forward_dynamics 返回加速度；inverse_dynamics 返回力矩；forward_kinematics 返回肘部和末端位置；energy 返回总机械能。
