# 第 0 章　前言与学习路线

## 学习目标

理解机器人动力学的研究对象、全书结构与学习方法。

运动学研究位姿，静力学研究平衡，动力学研究运动与力矩的关系。对 n 自由度机器人，广义坐标为 $q\in\mathbb{R}^n$，状态为 $x=[q^T,\dot q^T]^T$。

- 正动力学：已知 $q,\dot q,\tau$，求 $\ddot q$。
- 逆动力学：已知 $q,\dot q,\ddot q$，求 $\tau$。

全书主线是：位姿变换 → 雅可比 → 能量与受力 → 动力学方程 → 数值积分 → 控制。

## 本章小结

动力学的核心接口是状态、加速度和力矩。本书以单摆和 2R 平面机械臂贯穿各章。
